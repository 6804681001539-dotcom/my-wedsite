# จัดเวลานักศึกษา — JWT Auth Demo

เว็บจัดตารางเรียน/งานและกิจกรรมพิเศษสำหรับนักศึกษา

## วิธีเปิดใช้งาน
1. เปิด `index.html` ในเบราว์เซอร์ หรือ
2. อัปโหลดไฟล์นี้ขึ้น GitHub repository แล้วเปิด GitHub Pages

## เผยแพร่ด้วย GitHub Pages
1. สร้าง repository ใหม่บน GitHub
2. อัปโหลด `index.html` และ `README.md`
3. ไปที่ **Settings → Pages**
4. ใน **Build and deployment** เลือก **Deploy from a branch**
5. เลือก branch `main` และ folder `/(root)` แล้วกด **Save**
6. รอสักครู่ จากนั้นเปิด URL ที่ GitHub Pages แสดงให้

## ข้อควรทราบ
- เวอร์ชันนี้เป็นเว็บ HTML/CSS/JavaScript ไฟล์เดียว ใช้ `localStorage` เก็บข้อมูลในเบราว์เซอร์เครื่องนั้น
- ระบบเข้าสู่ระบบ/JWT ในไฟล์นี้เป็น **ตัวอย่างจำลองฝั่งหน้าเว็บ** ไม่ใช่ระบบยืนยันตัวตนที่ปลอดภัยสำหรับใช้งานจริง
- บัญชีผู้ใช้และข้อมูลจะไม่ sync ข้ามอุปกรณ์ และการล้างข้อมูลเบราว์เซอร์อาจทำให้ข้อมูลหาย
- Google Fonts ต้องใช้อินเทอร์เน็ตเพื่อโหลดแบบอักษร
